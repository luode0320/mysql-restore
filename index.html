IBD 表空间恢复

页面只指定恢复对象，工具负责根据 DDL 创建库表、丢弃表空间和导入表空间。 IBD 文件或库目录由人工移动到新的 MySQL data 目录，工具容器不会移动宿主机或其他 MySQL 容器里的数据文件。

输入 binance 输入 binance/user.ibd 人工移动 IBD
准备阶段 建库建表 + DISCARD
人工步骤 mv IBD 到新 data 目录
导入阶段 IMPORT TABLESPACE

恢复任务

填写库名会恢复该库 DDL 目录下的所有表；填写 库名/表名.ibd 只恢复单表。

执行步骤示例

1. 先点准备恢复，让 MySQL 创建空表并执行 DISCARD TABLESPACE。
2. 手动移动整个库目录： 
mv -f /old-mysql-data/binance /new-mysql-data/binance
或手动移动单表文件： 
mv -f /old-mysql-data/binance/user.ibd /new-mysql-data/binance/user.ibd
chown -R 999:999 /usr/local/src/mysql/data/binance
chmod 660 /usr/local/src/mysql/data/binance/*.ibd
3. 确认新 MySQL 的 data 目录里存在对应 .ibd 文件后，再点击导入表空间。
